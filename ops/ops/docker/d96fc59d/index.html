使用Docker搭建3主3从Redis集群

📁 环境概览

  1. 创建自定义 bridge 网络（便于容器间通信）
  2. 需要启动6 个 Redis 容器（3主3从，端口 7000～7005）
  3. 配置每个 Redis 实例启用集群模式
  4. 使用 redis-cli --cluster create 创建集群

角色 容器名 端口
Master 1 redis-master-1 7000
Master 2 redis-master-2 7001
Master 3 redis-master-3 7002
Replica 1 redis-replica-1 7003
Replica 2 redis-replica-2 7004
Replica 3 redis-replica-3 7005

**🚀**创建一键执行脚本

/ 换行的时候，后面不能再有任何字符

cat -A you.sh 可以看到隐藏字符

可以先把镜像下载好

vi create_redis_cluster.sh

注意此为一键执行，所以全部建在一台主机上，只用于测试，生产需要部署在多台主机上，命令把循环换成单条就行

  • --cluster-yes

自动回答 “yes”，跳过交互式确认提示

  • --cluster-replicas 1

为每个主节点（master）分配 1 个从节点（replica/slave）

节点顺序会影响分配结果（前 M 个倾向于做 master）

  • 如果出现**WARNING: IPv4 forwarding is disabled. Networking will not work.** 这是一个关键警告，说明你的 Docker 宿主机未启用 IP 转发（IP forwarding），这会导致：

    • 容器之间无法通信（即使在同一自定义网络）

    • Redis 集群节点互相“看不见”，集群创建失败

    • 从宿主机可能能访问单个 Redis，但集群内部 gossip 通信会失败

      • 临时启用（重启后失效）
      • 永久启用
