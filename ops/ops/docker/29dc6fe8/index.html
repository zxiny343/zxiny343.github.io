Docker常用命令

发表于2026-04-12|更新于2026-04-12|opsdocker

Docker 命令

1. docker images

用于列出本地主机上的镜像

  • docker images

只显示顶层镜像,中间层镜像（构建过程中产生的临时层）被隐藏

  • docker images -a

显示所有镜像,包括顶层镜像和中间层镜像

顶层镜像: 指有明确的 REPOSITORY 和 TAG 的镜像，通常是用户直接拉取或构建生成的镜像

中间层镜像:构建过程中产生的临时层

日常使用一般不需要加 -a，除非你在调试构建缓存、排查磁盘空间问题，或想彻底清理未引用的镜像层。

  • docker images -q

只显示镜像 ID

  • 按名称过滤

按名称过滤

  • docker images -f “dangling=true”

显示悬空镜像

构建新镜像时：当你重新构建一个同名镜像（如 myapp:latest），旧的顶层镜像会失去标签，变成 <none>:<none>。如果它也不再被其他镜像引用，就成为悬空镜像。没有名字、没有标签，也没有子镜像依赖它。

2. docker search

用于从 Docker Hub 搜索镜像

  • docker search nginx

搜索 nginx 相关镜像

其他参数作用不大

3. docker pull

用于从镜像仓库（默认是 Docker Hub）拉取镜像到本地

  • docker pull nginx

拉取最新版 nginx（等价于 nginx:latest）

  • docker pull redis:7.0-alpine

拉取指定标签的镜像

3.1 若本地已存在相同镜像（相同 repo + tag + digest），则不会重复拉取

3.2 生产环境应避免依赖 latest，而应使用明确的语义化标签（如 v1.2.3 或 1.25.3）以保证可重现性

3.3 拉取私有仓库镜像时，需先 docker login 认证

4. docker rm

用于删除一个或多个已停止的容器

  • 删除单个已停止的容器
  • 删除多个容器
  • 强制删除正在运行的容器
  • 删除容器及其匿名数据卷
  • 删除所有已停止的容器

5. docker rmi

用于删除本地镜像（image）

  • 删除指定镜像（通过名称或 ID）
  • 强制删除被容器引用的镜像
  • 删除所有悬空镜像

6. docker system

用于管理 Docker 主机系统资源的命令，主要用于查看磁盘使用情况和清理未使用的数据

  • 查看磁盘占用概览
  • 详细查看各组件占用
  • 清理悬空资源
  • 彻底清理（包括所有未用镜像和卷）

prune 操作不可逆，尤其是带 --volumes 时会永久删除数据卷中的数据，请确保无重要数据。

7. docker run

从镜像创建并启动一个新容器

  • 后台运行 Nginx，并映射端口
  1. -d :后台运行容器
  2. -p :端口映射， 主机 8080 访问容器 80
  3. –name :为容器指定自定义名称 ，否则 Docker 自动生成随机名运行 MySQL 并设置环境变量和持久化数据
  • 交互式进入 Ubuntu 容器
  1. -i :交互式运行,-t :分配伪终端，通常一起使用。交互式运行-常用于调试
  2. -rm :容器退出后自动删除（适合临时任务，避免残留）
  • 运行 MySQL 并设置环境变量和持久化数据
  1. -e :设置环境变量
  2. -v :挂载主机目录或卷到容器

8. docker start/stop/restart

start启动已经停止的容器

从 docker ps -a 的停止状态变成UP。

重新进入已经启动的 容器

9. docker inspect

用于查看 Docker 对象（容器、镜像、卷、网络等）的详细底层信息

10. docker exec

用于在已运行的容器中执行新命令

  • 进入容器的交互式 shell
  • 在容器中执行单条命令（非交互）

11. docker cp

用于在容器与本地文件系统之间复制文件或目录

  • 从容器复制文件到主机
  • 从主机复制配置文件到容器
  • 复制整个目录

12. docker commit

  • 提交一个镜像
