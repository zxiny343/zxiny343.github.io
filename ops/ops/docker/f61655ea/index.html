Dockerfile

一、Dockerfile 是什么

Dockerfile 是一个文本文件，它通过一系列指令定义如何构建一个 Docker 镜像。

二、Dockerfile 的基本结构

一个最简单的 Dockerfile 通常包含以下几类指令：

  1. FROM：指定基础镜像
  2. WORKDIR：设置工作目录
  3. COPY / ADD：拷贝文件
  4. RUN：构建阶段执行命令
  5. CMD / ENTRYPOINT：容器启动命令

简单实例

三、DockerFile基础知识

  1. 每条指令必须大写，且后面至少跟一个参数
  2. #表示注释
  3. 指令从上到下依次执行
  4. 每条指令都会创建一个新的镜像层，并对镜像层进行提交

四、保留字

指令 作用 其他
FROM 指定已存在的一个基础镜像 必须在第一行
RUN 构建(build)时执行命令 RUN <命令> 等同于在终端执行shell命令
EXPOSE 声明端口 对外暴露端口
WORKDIR 设置工作目录 进入容器后，默认的进入目录
ENV 设置环境变量
ADD 拷贝 + 自动解压 将宿主机上的文件拷贝进镜像并自动解压，支持 URL 下载文件
COPY 拷贝文件
CMD 指定容器启动后要干的事情

  • ENV

ENV 是做什么的

ENV 用于在 镜像中定义环境变量，这些变量在以下阶段都可用：

  • 后续 Dockerfile 的构建阶段（RUN 中可引用）
  • 容器运行阶段（应用程序可读取）
  • 写法键值对形式

本质作用：

把“可配置项”从代码中剥离出来。

每条 ENV 都会形成一个镜像层

  • ENV 定义后，可直接在 RUN 中通过 $变量名 使用
