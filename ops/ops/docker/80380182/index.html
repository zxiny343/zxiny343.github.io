Docker-Compose

一、是什么

​ Docker Compose 是用于定义和运行多容器应用的编排工具，通过一个 docker-compose.yml 文件统一管理容器、网络、卷。

​ 需要定义一个YAML格式的配置文件docker-compose.yml，配置了多个容器之间的调用关系。

​ Docker Compose 是Docker官方的开源项目，负责实现对Docker容器集群的快速编排。

二、常用命令

命令 作用
docker-compose up 启动所有docker-compose服务
docker-compose up -d 启动所有docker-compose服务，并后台运行
docker-compose down 停止并删除 容器 + 网络
docker-compose down -v 同时删除 volume（⚠ 数据会被删除）
docker-compose up –build 重新构建镜像后启动
docker-compose stop 仅停止容器，不删除
docker-compose restart 重启
docker-compose restart 服务名 重启
docker-compose ps 展示当前compose编排的运行的中的容器
docker-compose top 展示当前compose编排过的容器进程
docker-compose logs 查看日志
docker-compose logs -f 实时日志
docker-compose logs -f mysql 查看指定服务
docker-compose up -d redis 单个服务启动
docker-compose stop redis 单个服务停止
docker-compose exec mysql bash 进入容器
docker-compose config -q 检查 compose 文件是否正确，加-q无输出代表无问题
docker-compose pull 拉取镜像
docker-compose config –services 查看服务列表
docker-compose -f docker-compose.yml up -d 指定 compose 文件
docker-compose rm 删除已停止的容器
