Docker 私有仓库

一、Docker 私有仓库的本质

Docker 私有仓库本质上是一个：

遵循 Docker Registry HTTP API v2 规范的镜像存储服务

它主要做三件事：

  1. 存储镜像 layer（二进制 blob）
  2. 存储 manifest（镜像元数据）
  3. 提供 pull / push 接口

Docker 官方提供了 registry 镜像作为参考实现。
