Docker 数据卷

一、数据卷概述

在 Docker 中，容器是无状态的。当容器被删除或重建时，容器内部文件系统中的数据也会随之消失。

为了解决数据持久化、数据共享以及容器与宿主机之间的数据解耦问题，Docker 提供了 数据卷（Volume） 机制。

二、 解决了什么问题

  • 容器删除导致数据丢失
  • 升级通常需要重建容器，容器升级困难
  • 多个容器之间数据无法直接共享数据
