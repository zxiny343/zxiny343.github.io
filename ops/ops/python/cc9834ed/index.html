6. 常见调度示例

任务 代码
每10秒 schedule.every(10).seconds.do(task)
每5分钟 schedule.every(5).minutes.do(task)
每小时 schedule.every().hour.do(task)
每小时15分 schedule.every().hour.at(":15").do(task)
每分钟15秒 schedule.every().minute.at(":15").do(task)
每天10:30 schedule.every().day.at("10:30").do(task)
每周一10:30 schedule.every().monday.at("10:30").do(task)
每三小时的第15分钟 schedule.every(3).hour.at(“:15”).do(task)
